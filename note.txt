## Pitfalls
# - EphemeralTmpfs STATE → reboot wipes cluster (need disk modules + ext4)
# - "admin kubeconfig missing; bootstrap first" → not on disk STATE
# - Worker Unauthorized / system:anonymous → missing token Secret and/or node-rbac
#   (should be auto after rebuild; else apply note.txt secret + examples/bootstrap/node-rbac.yaml)
# - Same hostname on two workers → identity clash
# - eth0 IPv6-only (fe80::) / no IPv4 → rebuild image. Fixes: ioctl-first lease
#   install (udhcpc hook, no tokio), rp_filter=2 (strict=1 drops DHCP retries),
#   BusyBox `ip` applet. Expect `IPv4 added via ioctl` / `udhcpc IPv4 lease`.
# - "UserNamespacesSupport is disabled: can't set hostUsers" → kernel
#   user.max_user_namespaces=0 and/or kubelet feature gate; rebuild image
#   (sysctl 65536 + kubelet/apiserver UserNamespacesSupport=true). Temporary:
#   kubectl -n kube-flannel patch ds kube-flannel-ds --type=json \
#     -p='[{"op":"remove","path":"/spec/template/spec/hostUsers"}]'
#   (only if the DS sets hostUsers)
# - Cilium "path /sys/fs/bpf ... not a shared mount" → rebuild image (PID 1
#   mounts /sys + bpffs as rshared; do NOT rshared `/`).
# - Cilium install then nodes NotReady + ktail/kubectl logs 401 → mount-bpf-fs
#   Bidirectional tore down host /proc. Uninstall Cilium, reboot, reinstall with:
#     --set bpf.autoMount.enabled=false \
#     --set cgroup.autoMount.enabled=false \
#     --set cgroup.hostRoot=/sys/fs/cgroup
#   (see examples/cni/cilium.md). Rebuild also heals /proc in supervise loop.
# - kubectl/ktail logs always 401 (pods/log Unauthorized) while list/get work →
#   kubelet missing authentication.x509.clientCAFile. Fixed in pertisk-kubelet
#   config (needs image rebuild). Not a ktail bug.
# - After clientCAFile: Forbidden user=kube-apiserver nodes/proxy → apply
#   examples/bootstrap/node-rbac.yaml (system:kube-apiserver-to-kubelet).
#   Now part of bootstrap finalize.
# - CP without control-plane role → rebuild image (bootstrap finalizes label +
#   NoSchedule taint). Existing cluster: kubectl label node <cp>
#   node-role.kubernetes.io/control-plane=
# - Reboot loses API / kubelet absent → fixed: restore /etc/kubernetes +
#   kubelet certs from STATE before kubelet start. Rebuild + reboot (or
#   pertiskctl bootstrap on already-bootstrapped CP after new image).
#   Symptom was: tls_bootstrap=true then "stat .../kubeconfig: no such file".
